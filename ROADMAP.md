The roadmap is a public [GitHub project board](https://github.com/orgs/HyperbolicLabs/projects) built from issues labeled `roadmap`. Each item is an issue the maintainers have triaged as valuable to users, so its discussion and status live in one place.

The board groups items as Now, Next and Later. Release milestones give an approximate order, not a promise of when something ships.

## Suggesting an item

Open an issue or start a [discussion](https://github.com/HyperbolicLabs/rental-operator/discussions) describing the problem you want solved. Maintainers triage new issues and label the ones they plan to work on `roadmap`. An idea that needs a design first, such as a new API field, is labeled `needs-design` until the design is agreed in the issue.
