1. Create a Secret with your Hyperbolic API key (in the namespace where your
   GPURentals will live). read -rs waits for you to paste the key without
   echoing it or keeping it in history:

   read -rs HYPERBOLIC_API_KEY
   kubectl create secret generic hyperbolic-key \
     --namespace <your-namespace> \
     --from-literal=api-key="$HYPERBOLIC_API_KEY"
   unset HYPERBOLIC_API_KEY
   kubectl label secret hyperbolic-key --namespace <your-namespace> \
     compute.hyperbolic.ai/credentials=true

2. Point a ProviderConfig at it:

   apiVersion: compute.hyperbolic.ai/v1alpha1
   kind: ProviderConfig
   metadata: { name: default, namespace: <your-namespace> }
   spec:
     credentials:
       secretRef: { name: hyperbolic-key, key: api-key }

3. Declare a rental:

   apiVersion: compute.hyperbolic.ai/v1alpha1
   kind: GPURental
   metadata: { name: train-run, namespace: <your-namespace> }
   spec:
     providerConfigRef: { name: default }
     gpuType: h100
     gpuCount: 8

   kubectl get gpurentals -n <your-namespace> -w

Delete the GPURental to terminate the rental and release the GPUs. Delete
your GPURentals before uninstalling the operator or deleting the cluster:
without the operator, nothing terminates them and they keep billing.
