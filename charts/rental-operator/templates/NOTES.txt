1. Create a Secret with your Hyperbolic API key (in the namespace where your
   GPURentals will live):

   kubectl create secret generic hyperbolic-key \
     --namespace <your-namespace> \
     --from-literal=api-key=sk_live_xxxxxxxxxxxxxxxxxxxx

2. Point a ProviderConfig at it:

   apiVersion: compute.hyperbolic.ai/v1alpha1
   kind: ProviderConfig
   metadata: { name: default, namespace: <your-namespace> }
   spec:
     apiKeySecretRef: { name: hyperbolic-key, key: api-key }

3. Declare a rental:

   apiVersion: compute.hyperbolic.ai/v1alpha1
   kind: GPURental
   metadata: { name: train-run, namespace: <your-namespace> }
   spec:
     providerConfigRef: { name: default }
     gpuType: h100
     gpuCount: 8

   kubectl get gpurentals -n <your-namespace> -w

Delete the GPURental to terminate the rental and release the GPUs.
