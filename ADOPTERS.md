# Adopters

This file lists organizations that use rental-operator. If yours does, add a row with a pull request. It helps the project, and it helps others see who runs it and how.

| Organization | Adoption level | Description |
| ------------ | -------------- | ----------- |

The adoption level is Production, Dev/Test, Trialing or Evaluating. An organization that must stay anonymous can list its industry instead of its name, such as "Fortune 500 financial services".
